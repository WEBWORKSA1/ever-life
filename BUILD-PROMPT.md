# Ever.Life — Phase-Wise Build Prompt

**Concept:** *Ever.Life — Live longer. Leave more.* A longevity + legacy hub.
- **Traffic engine:** free longevity tools and guides.
- **Revenue engine:** high-CPC AdSense inventory (insurance, estate, health) plus a lead-generation funnel to licensed professionals.

## Why this idea wins (numbers and logic)

| Lever | Data point | Implication |
|---|---|---|
| Ad value | Insurance cost-per-lead ≈ **$74** (WordStream/LocaliQ 2026 benchmarks via WebTonic); insurance and legal are perennial top-CPC AdSense verticals | Every legacy/insurance pageview carries premium ad bids |
| Market | Human longevity market forecast to reach **~$69B by 2032 at ~16.8% CAGR** (MarkNtel Advisors) | Rising search demand, rising advertiser budgets |
| Funnel proof | Northwestern Mutual and John Hancock run lifespan calculators as insurance top-of-funnel | "How long will I live?" leads naturally to "Who's protected if it's shorter?" |
| Lead resale | Life / final-expense / estate leads sell to agents, brokers and estate lawyers (typical market $15–$80+ per qualified lead) | Second revenue stream independent of AdSense RPM |
| Domain fit | "Ever" + "Life" = longevity (*ever-lasting life*) and legacy (*what lives on*) | One brand covers both halves without stretching |

**Rejected alternatives:**
- **Pure longevity blog:** monetization is weaker.
- **Memorial/obituary site:** the SERP is saturated by incumbents.
- **Generic "life" magazine:** no intent, so low RPM.

## PHASE 1 — Foundation and AdSense readiness

```
Build a static, GitHub-Pages-compatible website for Ever.Life (longevity + legacy hub).
Stack: plain HTML/CSS/vanilla JS generated by a Python build script (build/build.py). No server, no database.

Requirements:
- Topbar on EVERY page: "Contact, if you are interested in this website / domain name / Sponsorship / Advertisement / Partnership" → https://web.works/contact
- AdSense script in <head> of every page:
  <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-6620975821265271" crossorigin="anonymous"></script>
  + <meta name="google-adsense-account" content="ca-pub-6620975821265271">
- ads.txt: google.com, pub-6620975821265271, DIRECT, f08c47fec0942fa0
- Required approval pages: About, Contact, Privacy Policy (AdSense cookie disclosure + opt-out links),
  Cookie Policy, Terms, Disclaimer & Trademark Notice, Editorial Policy.
- sitemap.xml, robots.txt, canonical URLs, Open Graph, JSON-LD (Organization, WebSite, Article, FAQPage, WebApplication).
- Cookie notice (Essential / Accept). Use AdSense's own certified CMP for EEA/UK.
- Design: evergreen + gold palette, Fraunces + Inter, tree-ring logo motif, dark mode, mobile-first, no horizontal scroll at 390px.
```

## PHASE 2 — Traffic engine: interactive tools

```
Build 4 private, in-browser tools (nothing stored server-side):
1. Life Expectancy Calculator:
   - Country/sex baseline plus survivor adjustment for current age.
   - 12 lifestyle factors (BMI, smoking, activity, diet, alcohol, sleep, social, stress, family history, check-ups, conditions).
   - Shows: estimate, range, factor breakdown, % of life lived, life-in-years grid.
   - CTA → insurance calculator.
2. Biological Age Test: 12 weighted questions → bio age vs calendar age, verdict, top-5 personalized tips.
3. Life Insurance Needs Calculator (DIME):
   - Inputs: debts + income × years + mortgage + education + final expenses − savings − existing cover.
   - Output rounds up to the nearest $50k, suggests a term length and income multiple.
   - CTA → lead form with ?need=insurance.
4. Legacy Checklist: 20 items in 5 groups, localStorage progress, print, reset. CTA → ?need=estate.
```

## PHASE 3 — Content engine: guides and video

```
Write 10 original long-form guides (1,300–1,800 words). Each includes:
- Lead paragraph, H2 sections, key-takeaway callout, table, 5-question FAQ, sources, disclaimer.
- A mid-article CTA and in-article ad slot.

Topics:
- Longevity: blue zones, healthspan vs lifespan, sleep, exercise, nutrition, biomarkers.
- Legacy: how much life insurance, term vs whole, estate planning basics, digital legacy.

Article template:
- Breadcrumbs, author/updated/read-time row, sticky TOC, sidebar CTA + newsletter, related articles.
- Article + FAQPage schema.

Video library:
- Verified TED/TED-Ed talks via a click-to-load youtube-nocookie facade.
- Category filters, "suggest a video" form, creator CTA.
```

## PHASE 4 — Revenue engine: lead generation

```
/get-matched.html — 4-step form with progress bar:
1. Need (auto-advance): life insurance, final expense, will & estate, retirement, longevity testing, other.
2. Age range, country, region, tobacco.
3. Coverage/budget, timeline, notes.
4. Name, email, phone, best time, explicit TCPA-style consent checkbox.

Also include:
- URL prefill (?need=), trust badges, "how it works", FAQ, partner link.
- Quick lead form on homepage + CTAs in every tool and every article.

All forms submit via AJAX to FormSubmit. The inbox address is stored reversed + base64 in main.js
and decoded only at submit time, so it never appears on any page.
```
